\section{The registered rule remains fixed}
The gap measures use the app's \texttt{isSerious} on final records.
Each device is compared with its own arm's routine. The miss share is
routine serious plies absent from the device's serious set, divided by
routine serious plies. The extra share is device serious plies absent from
the routine's set, divided by device serious plies. All played plies of
both sides count. Unknown records are not serious under that instrument.
Shares pool counts over games. Changes are candidate minus baseline.

The bootstrap uses \Draws{} Poisson(\PoissonMean) draws over games,
seed \Seed, with shared game weights across arms and profiles.
Ordinary percentile intervals have \Confidence\% nominal coverage.
The \Effects{} decision effects use Bonferroni intervals with
\CorrectedConfidence\% nominal coverage and linearly interpolated quantiles.
Invalid estimates cannot pass.

For each device, both point changes must be negative. At least one corrected
upper bound must be below zero, and the other's lower bound must be at most
zero. Both devices must pass to establish narrowing. Absolute agreement is
reported only when all device shares' ordinary upper bounds fall below
\AgreementLine\%. It provides no alternate route to keeping the candidate.

The quality guard uses each profile's common attempted second looks,
including incomplete ones. A fresh \ReferenceNodes-node search with
\Candidates{} candidates and full history supplies the reference. An
incomplete or non-exact reference gets \RetryWord{} fresh retry at the same
budget; the first valid attempt is used. An unresolved reference blocks the
affected guard. The app's \texttt{judgeMove} and \texttt{isSerious} supply
raw serious-or-not verdicts. Incomplete arm evidence counts as incorrect.
Candidate minus baseline error must have a corrected upper bound below
\QualityMargin{} percentage point at every profile. A lower bound above
that margin means worse; otherwise the guard is inconclusive. Keep for a
port only when both device gaps narrow and every quality guard passes.
Time and depth are descriptive, without an adoption threshold.

any deciding metric. The README recorded the amendment separately before

persistence wrapper saved the first observed document and trace before the
existing equality gate. No search, review call, evidence calculation or

build failure or timeout. The observed stage stopped on a reproduction

is retained, without an accepted timing file. Another \MissingFirstGames{}
games have no first observed replay. No produced output was rerun or replaced.

outputs are absent. The registered disposition remains uncomputed.

\section{What the app takes}
Not yet. The acquisition gate must pass before this study can supply a
verdict. No app port or saved-review migration was made. A kept candidate
would clear the analyst before the selected initial second looks and
adaptive retries on phone, desktop and routine. Sweeps, quotas, tablebase,
teaching and saved-review policy would remain as they are. Game Review opens
a saved device review first and offers the routine's review for comparison
when available. Saved judgments remain until an explicit rebuild.

Actual devices use a \DeviceHashSize{} MB hash and an evaluation cache.
Clearing the hash leaves that cache policy unchanged. Other analyst work
could interleave between reset and search. This serial, uncached Node design
does not settle those device questions. The planned higher-budget fresh
reference is not ground truth and may favor the fresh candidate's search
path. Its guard covers common attempted looks, not every move or coaching
text. None of those quality comparisons was reached here.
